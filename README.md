# 🎯 Marrakech - Admin Dashboard

## 🚀 Como Usar

### Pré-requisito: Node.js
Você precisa ter **Node.js** instalado. Baixe em: https://nodejs.org

1. Baixe e execute o instalador
2. **Importante:** Marque "Add to PATH" durante a instalação
3. Reinicie o computador

### Execução

**Primeira vez:**
1. Duplo clique em `INSTALAR_E_EXECUTAR.bat`
2. Espere tudo instalar e compilar (pode levar 2-3 minutos)
3. O servidor iniciará e mostrará: `http://localhost:3000/admin/login`

**Próximas vezes:**
- Duplo clique em `INICIAR_SERVIDOR.bat` para abrir direto

### 📍 Acessar o Dashboard
Abra seu navegador e vá para:
```
http://localhost:3000/admin/login
```

### ⚠️ Importante
- Deixe a **janela do terminal ABERTA** enquanto usar o app
- Para parar, feche a janela ou pressione `Ctrl+C`

## 🐛 Se tiver problemas

### Erro: "Node.js não foi encontrado"
- Instale Node.js: https://nodejs.org
- Reinicie após instalar
- Marque "Add to PATH" na instalação

### Porta 3000 já em uso
- Modifique `INICIAR_SERVIDOR.bat` e adicione: `set PORT=3001`

### Aplicação lenta na primeira vez
- Normal! Next.js está compilando
- Aguarde 1-2 minutos
